1. GENEL BAKIŞ
==============================================================

Mevcut web sitesi (müşteri sipariş, barista paneli, admin paneli)
aynen native Android uygulamasına dönüştürülecektir.

Mevcut PHP + MySQL backend API'leri (orders, status, poll, 
end-of-day, reports) aynen kullanılacak, sadece frontend 
tarafı Kotlin ile yeniden yazılacaktır.

Teknoloji Yığını:
  - Kotlin (dil)
  - Jetpack Compose (modern UI framework)
  - Material 3 (tasarım sistemi)
  - Retrofit + OkHttp (API iletişimi)
  - Hilt (bağımlılık enjeksiyonu / dependency injection)
  - MVVM mimarisi (Model-View-ViewModel)
  - CameraX + ML Kit (QR kod okuma)
  - Firebase Cloud Messaging (push bildirim)
  - Coroutines + Flow (asenkron işlemler)
  - Navigation Compose (ekran geçişleri)
  - DataStore (yerel veri saklama)

Uygulama Yapısı:
  - Tek uygulama, 3 farklı rol/mod:
    1) Müşteri Modu (varsayılan)
    2) Barista Modu (şifre ile giriş)
    3) Admin Modu (şifre ile giriş)

3. API ENTEGRASYONU (Mevcut Backend'e Bağlanma)
==============================================================

Mevcut PHP API endpoint'leri aynen kullanılacak.
Base URL: https://yakuphanuslu.com/coffee/api/

Adım 3.1 — API Service Interface (ApiService.kt)

  interface ApiService {
  
    // Tüm siparişleri getir (barista/admin)
    @GET("orders.php")
    suspend fun getOrders(): List<Order>
  
    // Müşteri token ile kendi siparişini sorgula
    @GET("orders.php")
    suspend fun getOrderByToken(
      @Query("customer_token") token: String
    ): Order
  
    // Yeni sipariş oluştur
    @POST("orders.php")
    suspend fun createOrder(
      @Body request: OrderRequest
    ): OrderResponse
  
    // Sipariş durumu güncelle (barista)
    @PUT("status.php")
    suspend fun updateStatus(
      @Body request: StatusRequest
    ): StatusResponse
  
    // Polling (son güncelleme zamanından beri)
    @GET("poll.php")
    suspend fun poll(
      @Query("since") since: String
    ): PollResponse
  
    // Günsonu yap (admin)
    @POST("end-of-day.php")
    suspend fun endOfDay(): EndOfDayResponse
  
    // Raporları listele
    @GET("reports.php")
    suspend fun getReports(): List<Report>
  
    // Rapor detayı
    @GET("reports.php")
    suspend fun getReportDetail(
      @Query("id") id: Int
    ): ReportDetail
  }

5. PUSH BİLDİRİM SİSTEMİ
==============================================================

Adım 5.1 — Firebase Projesi Oluştur
  - Firebase Console'dan yeni proje oluştur
  - Android uygulamasını ekle (paket adı: com.brewandbean.app)
  - google-services.json dosyasını indir → app/ klasörüne koy

Adım 5.2 — Müşteri Bildirimi
  Seçenek A (Basit — Polling tabanlı, mevcut sistemle uyumlu):
    - Uygulama açıkken: ViewModel içinde 3 sn'de bir poll
    - Durum "hazir" olunca NotificationManager ile yerel bildirim
    - Avantaj: Backend değişikliği gerektirmez
    - Dezavantaj: Uygulama kapalıyken bildirim gelmez

  Seçenek B (Gelişmiş — FCM tabanlı):
    - status.php dosyasına FCM push gönderme kodu ekle
    - Müşteri token'ı ile birlikte FCM device token'ı da kaydet
    - Durum "hazir" olunca sunucu FCM'e istek gönderir
    - Avantaj: Uygulama kapalıyken bile bildirim gelir
    - Dezavantaj: Backend'de değişiklik gerekir

  Öneri: Başlangıçta Seçenek A ile başla, sonra B'ye geç.
